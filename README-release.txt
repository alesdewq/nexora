NEXORA — диагностика и базовый аудит безопасности Windows 10/11 (x64)
=====================================================================

Запуск: распакуйте архив в любую папку и запустите Nexora.exe. Установка и права администратора не нужны.
.NET устанавливать не требуется — он встроен в программу.

Что делает: проверяет причины тормозов и перегрева, собирает сведения о системе, проводит базовую проверку
безопасности (Defender, брандмауэр, UAC, шифрование, удалённый доступ, автозагрузка, открытые порты),
показывает кандидатов на очистку и формирует отчёт HTML/JSON.

Принципы:
  * Проверка только читает сведения о системе и ничего не меняет.
  * Очистка временных файлов, корзины, отключение автозагрузки и запуск деинсталлятора — только по кнопке
    и после вашего подтверждения; каждое действие записывается в журнал
    %LOCALAPPDATA%\NEXORA\logs\actions.jsonl.
  * Программа не отправляет данные в сеть. Отчёты хранятся локально: %LOCALAPPDATA%\NEXORA\reports.
  * Недоступные данные показываются как «не удалось проверить», а не выдумываются.
  * «Проблем не найдено» не означает, что компьютер безопасен. NEXORA не антивирус.

Windows SmartScreen может предупредить о неизвестном издателе: программа не подписана сертификатом.
Проверить целостность архива можно по SHA256 со страницы загрузки.

Командная строка (для специалистов):
  Nexora.exe --scan <папка> [--duration 30] [--no-drivers] [--mask]   — проверка без окна, report.html/json
