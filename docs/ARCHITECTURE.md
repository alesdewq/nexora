# ARCHITECTURE

## Платформа (проверено на 2026-10-19)
- **.NET 10 (LTS, до ноября 2028)**, C#, WPF. Выпуск — самодостаточный single-file `Nexora.exe` (win-x64), .NET устанавливать не нужно.
- **Целевые ОС: Windows 10 22H2 и Windows 11 (24H2/25H2), x64** (решение пользователя). Разработка и тесты — Windows 10 22H2 (19045).

## Проекты и зависимости
```
Nexora.Core ─────────────┐  модели: CheckResult (фабрики с инвариантами), Measured<T>, Evidence, Severity/Kind/Confidence, Assessment
Nexora.Diagnostics ──────┤  снимки и анализ: инвентаризация (+ таблица жизненного цикла Windows), производительность, журнал
Nexora.SecurityAudit ────┤  учётные записи, Defender/брандмауэр/UAC/BitLocker/Winlogon, RDP/SMB/WinRM, автозагрузка;
                         │  пространство имён Malware — оценка по данным Defender (отдельный проект не нужен: ~100 строк)
Nexora.NetworkAudit ─────┤  сокеты, сопоставление с правилами брандмауэра (порт/протокол/программа/служба)
Nexora.Cleanup ──────────┤  предпросмотр, PathGuard, CleanupPlan (только с подтверждением), SafeCleaner + IFileRemover, журнал
Nexora.Reporting ────────┘  ReportDocument (схема v1), JSON, HTML, маскирование, сравнение, история, отметки устранения
        ▲  все — net10.0, без обращений к системе → тестируются синтетическими снимками
Nexora.Platform (net10.0-windows)  сбор: WMI/CIM (System.Management), реестр, PDH, iphlpapi, netapi32, wintrust, COM
                                   (HNetCfg.FwPolicy2, Schedule.Service, Shell); Scanner — оркестратор; Actions — этап 8
Nexora.App (WPF)                   MVVM без внешних библиотек; режимы --scan и --smoke-test [--with-scan|--demo]
```
Отклонение от предложенной структуры ТЗ: добавлен `Nexora.Platform` (весь Windows-специфичный код в одном месте, остальное
тестируется без Windows-API); `Nexora.MalwareAssessment` стал пространством имён в SecurityAudit. Тестовых проектов 8 (по одному на модуль + Platform).

## Поток данных
`Scanner.RunAsync` → (1) производительность измеряется первой, пока NEXORA сама не нагружает систему → (2) инвентаризация →
(3) безопасность (с контекстом редакции/типа корпуса из п. 2) → (4) сеть → (5) файлы → анализаторы → `ReportDocument`
(находки + технические данные) → автосохранение в `%LOCALAPPDATA%\NEXORA\reports`. Ошибка модуля не останавливает остальные:
модуль попадает в «пропущенные» с причиной.

## Ключевые решения
1. **Каждый результат — `CheckResult`** со статусом Ok/Finding/Unavailable/Failed, источником, ограничениями, уверенностью.
   Инварианты в фабриках: недоступное = «Не удалось проверить»; эвристика не бывает «Критической» или с высокой уверенностью;
   у замечания всегда есть «почему» и «что делать».
2. **Measured<T>** вместо «0 по умолчанию»: значение + источник или «данные недоступны» + причина. В JSON — `{value|unavailable, source}`.
3. **Права**: UI не требует администратора (`asInvoker`). Недоступные без прав данные → «Не удалось проверить: нужны права администратора».
   Запасные источники без WMI: сборка Windows и имя — реестр, память — GlobalMemoryStatusEx, диски — DriveInfo, время работы — TickCount64.
   Отказ WMI в пространстве имён кэшируется (ограниченный токен иначе тратит секунды на каждый запрос).
4. **Локализация**: группы — по SID (S-1-5-32-544), счётчики — PdhAddEnglishCounter (русская Windows), BitLocker без прав — свойство оболочки.
5. **Температура**: только термозоны ACPI через PDH (+ «% Passive Limit» как признак троттлинга). Сторонние драйверы датчиков не используются.
6. **Подписи**: WinVerifyTrust без сети (без проверки отзыва, только кэш); файлы в %windir% (каталожные подписи) не проверяются.
7. **Этап 8**: удаление — только элементы подтверждённого плана из предпросмотра; перед каждым файлом PathGuard (корень, «..», UNC,
   ADS, ссылки на всём пути, тот же размер/время) → по умолчанию в корзину (SHFileOperation FOF_ALLOWUNDO). Автозагрузка — через
   StartupApproved в HKCU (как Диспетчер задач), исходная запись не трогается. Деинсталляция — разбор UninstallString без оболочки,
   cmd/powershell/mshta/rundll32 запрещены, MSI /I → /X.
8. **Зависимости рантайма**: только System.Management и System.Diagnostics.EventLog (Microsoft, MIT). Тесты: xUnit v3.
