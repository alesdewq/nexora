# ROADMAP

Каждый этап: короткий план и критерии готовности → реализация → запуск тестов → отчёт (что проверено, что нет и почему).

| # | Этап | Критерии готовности | Статус |
|---|------|---------------------|--------|
| 0 | Осмотр среды, план, документация | ROADMAP/ARCHITECTURE/SECURITY/LIMITATIONS, задача 001, журнал | готово 2026-10-19 |
| 1 | Каркас WPF + модули + сборка + тесты | `dotnet build` и `dotnet test` без ошибок на Windows; приложение открывается без прав администратора; 8 разделов-заглушек | готово 2026-10-19 (20 тестов, smoke без прав администратора) |
| 2 | Read-only инвентаризация | ОС/сборка/редакция, CPU/RAM, диски, адаптеры/IP, программы (реестр Uninstall), обновления, драйверы, uptime; каждое поле — значение или «недоступно» + источник | ожидает |
| 3 | Производительность и процессы | Сэмплинг CPU/RAM/диска N минут; топ процессов; устойчивая нагрузка vs пик; температура только из реального датчика, иначе «недоступно»; уровень уверенности | ожидает |
| 4 | Пользователи, группы, базовая безопасность | Локальные учётки и группы (Administrators), Defender, Firewall, UAC, BitLocker, RDP/SMB/WinRM, автозагрузка/задачи/службы — с контекстом, без автоматического «уязвимость» | ожидает |
| 5 | Локальный сетевой аудит | TCP/UDP-сокеты → процесс/служба → правила брандмауэра; «слушает локально» ≠ «доступен из сети»; никаких сканирований других хостов | ожидает |
| 6 | Отчёты HTML/JSON + интерфейс результатов | Отчёт со всеми полями из ТЗ; предупреждение о чувствительных данных перед экспортом; сравнение двух отчётов | ожидает |
| 7 | Предпросмотр очистки (без удаления) | Temp, корзина (только просмотр), крупные файлы, деинсталляторы, автозагрузка — только список с обоснованием | ожидает |
| 8 | Безопасная очистка — **только после отдельного согласования** | Подтверждение на каждую операцию, повторная проверка пути, защита от reparse points/`..`, журнал, отмена где возможно; тесты на временных каталогах/VM | заблокирован решением пользователя |
| 9 | Тесты, документация, установщик, подготовка к публикации | MSI/ZIP, USER_GUIDE, TEST_PLAN; публикация только с разрешения | ожидает |

## Вне MVP
Доменная инвентаризация AD, вызов сканирования Defender (опция с разрешения), PDF-отчёт, «чистка реестра» (не планируется вовсе).
