# SECURITY

## Что приложение делает
Читает сведения о системе через документированные интерфейсы Windows и показывает их пользователю. Отчёты сохраняются локально.

## Чего приложение не делает (гарантии MVP)
- Не меняет файлы, программы, службы, учётные записи, брандмауэр, Defender, обновления (Этапы 0–7 — только чтение).
- Не отключает и не обходит защитные механизмы; не предлагает отключать защиту ради производительности.
- Не отправляет данные в сеть: нет телеметрии, обновлений «из облака», загрузки файлов в сторонние сервисы.
- Не сканирует другие устройства и внешние адреса.
- Не собирает пароли, токены, содержимое документов, историю браузера.
- Не выполняет команды оболочки, собранные из пользовательского ввода (WMI/API вызываются напрямую, без `cmd /c` и PowerShell-строк).

## Изменения системы (Этап 8, после согласования)
Каждая операция: точный объект и последствия → явное подтверждение → повторная проверка пути (нормализация, запрет
`..`, reparse points/симлинков/junction вне категории) → действие только внутри разрешённой категории → журнал →
отмена/восстановление, где возможно. Программы удаляются только штатным деинсталлятором. Автозагрузка отключается обратимо.

## Чувствительные данные в отчётах
Отчёт может содержать имена учётных записей, имя компьютера, локальные IP, пути. Перед экспортом — предупреждение;
опция маскирования (имя ПК, пользователи, IP, пути профиля). Отчёты реальных систем не коммитятся (`.gitignore`).

## Разработка
- Код не публикуется на GitHub и релизы не создаются без разрешения пользователя.
- Деструктивные тесты — только на специально созданных временных каталогах или в VM. Реальное вредоносное ПО не скачивается;
  для «обнаружений» используются фиктивные данные (заглушки источника Defender).
- Новые зависимости — только после проверки назначения, лицензии, активности и известных уязвимостей.
