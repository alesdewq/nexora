# SECURITY

## Что приложение делает
Читает сведения о системе через документированные интерфейсы Windows и показывает их пользователю. Отчёты сохраняются локально.

## Чего приложение не делает
- Во время проверки не меняет файлы, программы, службы, учётные записи, брандмауэр, Defender, обновления. Методы WMI не вызываются — только SELECT.
- Не отключает и не обходит защиту; не предлагает отключать защиту ради производительности; не трогает карантин Defender.
- Не отправляет данные в сеть: нет телеметрии, обновлений, облака. Проверено: во время полной проверки у процесса 0 сетевых подключений
  (Get-NetTCPConnection/Get-NetUDPEndpoint, 2026-10-19). WinVerifyTrust вызывается с запретом сетевых запросов.
- Не сканирует другие устройства и внешние адреса.
- Не собирает пароли, токены, содержимое документов, историю браузера.
- Не выполняет команды оболочки, собранные из ввода. Единственный запуск внешней программы — штатный деинсталлятор из реестра
  после подтверждения (без cmd/PowerShell; обёртки запрещены).

## Действия, меняющие систему (этап 8)
| Действие | Ограничения | Обратимость | Журнал |
|---|---|---|---|
| Очистка временных файлов пользователя | только %TEMP%, только файлы старше 24 ч из предпросмотра; PathGuard перед каждым файлом; ссылки не обходятся | по умолчанию в корзину | да |
| Очистка корзины | только целиком, функцией Windows, после подтверждения с предупреждением о необратимости | нет (предупреждение) | да |
| Отключение/включение автозагрузки | только записи текущего пользователя (HKCU Run, своя папка «Автозагрузка»); механизм StartupApproved | да, кнопкой или в Диспетчере задач | да, с прежним значением |
| Удаление программы | запускается штатный деинсталлятор; файлы вручную не удаляются | зависит от программы | да |

Журнал: `%LOCALAPPDATA%\NEXORA\logs\actions.jsonl` (время, действие, объект, результат, подробности).
Не реализуется: чистка реестра, удаление системных файлов, драйверов, точек восстановления, содержимого пользовательских папок,
изменение служб, учётных записей, брандмауэра и Defender.

## Чувствительные данные в отчётах
Отчёт может содержать имена учётных записей, имя компьютера, локальные IP, пути. Перед экспортом — предупреждение; маскирование
включено по умолчанию (имя ПК, имена пользователей, путь профиля, IPv4/IPv6 кроме localhost/0.0.0.0, MAC). История хранится локально
без маскирования (это данные самого пользователя на его компьютере). Отчёты реальных систем не коммитятся (`.gitignore`).

## Разработка
- Код не публикуется на GitHub без разрешения владельца.
- Деструктивные тесты — только на временных каталогах, созданных тестом (в том числе junction-ссылки). Реальное вредоносное ПО не используется:
  «обнаружения» — синтетические данные.
- Smoke-тест выполняет настоящую проверку, но все диалоги подтверждения отвечают «Нет», и тест падает, если в журнале появилось действие.
