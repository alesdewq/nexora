# LIMITATIONS

- Проверено пока только на Windows 10 22H2 (19045). Windows 11 заявлена целевой, но тестовой машины с ней нет.
- NEXORA не антивирус и не сканер уязвимостей. Отсутствие находок **не значит**, что система безопасна.
- Данные Defender доступны только если Defender — активный антивирус; со сторонним антивирусом часть проверок будет «не удалось проверить».
- Температура CPU на многих ноутбуках через штатные интерфейсы недоступна или показывает температуру зоны ACPI, а не ядер.
- BitLocker, часть журналов событий и сведения о некоторых службах требуют прав администратора.
- Локальные данные о портах не говорят, доступен ли порт из интернета (NAT, внешний брандмауэр, провайдер).
- На Windows 10 Home нет Hyper-V/Sandbox, поэтому тесты очистки — во временных каталогах или VMware VM.
- Локализованные имена групп (Администраторы/Administrators) обрабатываются по SID (S-1-5-32-544), а не по имени.
