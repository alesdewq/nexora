# LIMITATIONS

## Общие
- NEXORA не антивирус и не сканер уязвимостей. Отсутствие находок **не значит**, что система безопасна или исправна.
- Проверено только на Windows 10 22H2 Home (19045), русская локализация. Windows 11 заявлена целевой, но тестовой машины нет.
- Не проверена работа под обычной учётной записью с UAC-фильтрованным токеном (нет такого сеанса). Проверено: полный токен
  администратора и ограниченный токен `runas /trustlevel:0x20000` — второй строже обычного пользователя (запрещён WMI).

## Данные и интерфейсы
- Defender: при стороннем антивирусе часть проверок «не применяется»; исключения без прав администратора недоступны.
- Температура — термозоны ACPI: на многих ноутбуках это не температура ядер, обновляется редко; нет зоны → «данные недоступны».
- Подробные SMART-счётчики требуют администратора и не читаются; используется оценка Windows (HealthStatus).
- Win32_QuickFixEngineering показывает не все обновления; срок поддержки Windows — из встроенной таблицы (на 2026-10-19).
- Подписка ESU для Windows 10 локально не проверяется.
- Каталожные подписи системных файлов не проверяются; неподписанный файл не считается вредоносным.
- Автозагрузка: не проверяются драйверы, расширения браузеров, WMI-подписки, AppInit и другие редкие механизмы.
- Сеть: «прослушивается» ≠ «доступен из интернета»; сопоставление с правилами брандмауэра упрощённое (без запрещающих правил,
  удалённых адресов, IPsec).
- Учётные записи: «последний вход» есть не для всех; флаг PasswordRequired неточен для учётных записей Microsoft.
- Группы по SID: локализованные имена групп не влияют на результат.

## Выпуск
- Программа не подписана — SmartScreen может предупредить. Установщика нет: портативный ZIP.
- PDF-отчёта нет (только HTML/JSON; HTML печатается в PDF средствами браузера).
- Нагрузка самой NEXORA (перечисление процессов раз в секунду) входит в измерение CPU — обычно доли процента.
