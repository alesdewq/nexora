# TEST_PLAN

## Автоматические тесты (`build\ci.ps1`, xUnit v3)
220 тестов, все пройдены 2026-10-19 (Debug и Release), сборка с `-warnaserror` без предупреждений.

| Проект | Что проверяется |
|---|---|
| Core.Tests | Measured<T> (недоступно ≠ 0), инварианты CheckResult (эвристика ≠ критично/высокая уверенность), Assessment никогда не говорит «безопасно» |
| Diagnostics.Tests | таблица жизненного цикла Windows (редакции, LTSC, неизвестные сборки), пороги диска/памяти/CPU, короткое наблюдение → низкая уверенность, нет датчика → «недоступно», недостоверная температура, троттлинг, журнал |
| SecurityAudit.Tests | Defender/сторонний AV, базы, исключения (широкие/узкие), брандмауэр по профилям и со сторонним продуктом, UAC, BitLocker с учётом редакции и корпуса, RDP/NLA, SMB1, Winlogon, админы по SID (в т. ч. без списка учётных записей), разбор командных строк, эвристики автозапуска (ни одна не «критическая»), статусы угроз |
| NetworkAudit.Tests | порты/диапазоны/ключевые слова правил, протокол, программа, служба правила, loopback, «локально ≠ интернет» |
| Cleanup.Tests | **только временные каталоги теста**: свежие файлы не трогаются, junction не обходится, PathGuard (вне корня, общий префикс, «..», UNC, ADS, точка в конце, путь через junction, изменённый/удалённый файл), план только из предпросмотра, занятый файл пропускается, журнал, разбор UninstallString (обёртки и относительные пути запрещены) |
| Reporting.Tests | JSON туда-обратно, новая схема отклоняется, HTML экранирует и не содержит скриптов, уровни подписаны текстом, маскирование (IP/IPv6/MAC/имена, не ломает время и версии), сравнение (не выполнившаяся проверка ≠ устранено), повреждённый файл истории, отметки устранения |
| Platform.Tests | на реальной системе, только чтение: инвентаризация, сэмплер, журнал без прав, безопасность, Authenticode, собственный loopback-сокет находится с PID, правила брандмауэра, полная проверка → согласованный отчёт, удаление только своего временного файла |

## Ручные/интеграционные проверки (выполнены 2026-10-19 на Windows 10 22H2 Home)
| Сценарий | Результат |
|---|---|
| Полная проверка с полным токеном администратора (`--scan`) | 49–51 проверка; выводы просмотрены вручную → найдены и исправлены 3 ложных/неточных вывода (скрытый PowerShell штатных заданий, правила брандмауэра другой службы, безымянные устройства) |
| Проверка с ограниченным токеном (`runas /trustlevel:0x20000`, WMI запрещён) | 42 проверки, 15 «не удалось проверить» с причиной, ничего не выдумано; найден и исправлен ложный вывод о числе администраторов; время 111 с → 27 с после кэша отказов WMI |
| Smoke-тест UI с настоящей проверкой (`--smoke-test --with-scan`) | PASS: все 8 разделов, раскрытая карточка; очистка и экспорт без подтверждения не выполняются, журнал пуст |
| То же без прав администратора | PASS |
| Опубликованный single-file exe | smoke PASS |
| Сетевая активность во время проверки | 0 TCP/UDP-подключений процесса |
| Скриншоты интерфейса | просмотрены; найдена и исправлена ошибка привязки ProgressBar (падение окна при открытии) |

## Не проверено
- Windows 11; обычный пользователь с UAC-фильтрованным токеном; другие локализации Windows; высокий DPI/масштаб > 100 %.
- Ручная работа с интерфейсом на рабочем столе (мышь, клавиатура, экранный диктор).
- Реальная очистка временных файлов, корзины, отключение автозагрузки и деинсталляция на рабочей системе — **намеренно** не выполнялись;
  логика проверена на временных каталогах, интерфейс — с отказом в подтверждении.
- Системы со сторонним антивирусом, с BitLocker, в домене, с активными угрозами Defender — только на синтетических данных.
