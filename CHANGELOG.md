# Changelog

## [0.9.0] — 2026-10-19 — MVP (этапы 2–9)
### Добавлено
- Инвентаризация: Windows (редакция, сборка, срок поддержки по таблице на 2026-10-19), CPU, RAM, диски и их состояние, сеть, программы,
  обновления, драйверы, устройства с ошибками, ожидание перезагрузки, время работы. Запасные источники без WMI.
- Производительность: наблюдение 30 с – 5 мин, процессы, диск, термозоны ACPI, снижение частоты, ошибки дисков/WHEA/выключения в журнале.
- Безопасность: учётные записи и «Администраторы» по SID, Defender/сторонний AV, базы, защита от подделки, исключения, брандмауэр,
  UAC, BitLocker, RDP/NLA, SMB1, WinRM, общие папки, Winlogon, автозагрузка с эвристиками, обнаружения Defender.
- Сеть: прослушиваемые порты → процесс → служба → правила брандмауэра.
- Файлы: предпросмотр временных файлов, корзины, крупных файлов.
- Действия с подтверждением и журналом: очистка temp (в корзину по умолчанию), очистка корзины, отключение/включение автозагрузки,
  запуск штатного деинсталлятора.
- Отчёты HTML/JSON с маскированием, локальная история, сравнение, статусы устранения. Интерфейс на 8 разделов.
- CLI `--scan`, `--smoke-test [--with-scan|--demo]`; скрипты `ci.ps1`, `publish.ps1`, `run-limited.ps1`.
### Исправлено по результатам проверки на реальной системе
- Ложное «подозрительно» для штатных заданий Windows со скрытым окном PowerShell.
- Правила брандмауэра другой службы того же svchost считались разрешающими.
- Безымянные устройства с ошибками — теперь с классом, кодом и идентификатором.
- Неизвестное состояние учётной записи считалось «включено» (ложное «много администраторов» без прав).
- Окно падало при открытии из-за двусторонней привязки ProgressBar к свойству только для чтения.
