NEXORA

Офлайн-приложение для Windows 10/11: почему компьютер тормозит и греется, что в нём установлено и насколько базово защищена система — с честным отчётом, где факт отделён от подозрения.

В разработке · Этап 0 из 9: план и архитектура · скачать пока нечего

Что будет проверять

01

Инвентаризация

Версия и сборка Windows, CPU, RAM, диски, сетевые адаптеры, программы, обновления, драйверы, время работы.

02

Тормоза и перегрев

Нагрузка CPU/RAM/диска по процессам за время наблюдения; устойчивая проблема против короткого пика. Температура — только из реального датчика.

03

Пользователи и права

Локальные учётные записи и группы, кто входит в «Администраторы», лишние права как повод для проверки.

04

Безопасность Windows

Defender и сигнатуры, брандмауэр, UAC, BitLocker, RDP/SMB/WinRM, автозагрузка, задачи и службы — с учётом контекста.

05

Сеть (локально)

Какие порты слушает компьютер, каким процессом и службой; правила брандмауэра. Другие устройства не сканируются.

06

Файлы и отчёт

Предпросмотр временных и крупных файлов без удаления; отчёт HTML/JSON и сравнение проверок во времени.

Принципы

  • Сначала только чтение. Диагностика ничего не меняет в системе.
  • Ничего не выдумывает. Нет данных — пишет «данные недоступны».
  • Факт ≠ подозрение. Каждый вывод — с источником, уверенностью и ограничениями.
  • Без сети. Ни телеметрии, ни облака, ни скрытых соединений.
  • Не отключает защиту. Defender, брандмауэр и обновления не трогает.
  • Без администратора для обычного просмотра.
  • Очистка — отдельно, с подтверждением каждой операции и журналом.
  • Не обещает невозможного: «проблем не найдено» ≠ «система безопасна».

Платформа

Windows 11 x64 — основная цель; Windows 10 22H2 — будет работать, но эта версия уже вне основной поддержки Microsoft, и NEXORA честно отметит это в отчёте. Стек: C#, .NET 10 LTS, WPF, штатные интерфейсы Windows (WMI/CIM, счётчики производительности, Win32 API).
